오늘의 초성(Hidden Vowels)은 웹(chosung.dosaem.com)과 iOS·Android 앱에서 같은 서버를 씁니다. 이 방침은 세 곳 모두에 적용됩니다.

이 서비스는 회원가입이 없습니다. 기록의 주인은 기기에 저장된 게스트 토큰 하나이고, 이름·전화번호·주소·생년월일·결제 정보는 받지 않습니다.

1. 수집하는 정보와 보유 기간

게스트 토큰
기록을 식별하는 임의의 문자열입니다. 첫 방문·첫 실행 때 서버가 발급하고 기기에 저장합니다. "내 기록 백업" 의 백업 코드가 이 토큰입니다. 계정 삭제 시 함께 삭제합니다.
계정 이메일
구글 또는 애플 계정을 연결할 때 제공자가 알려주는 이메일과 고유 식별자를 저장합니다. 연결하지 않으면 수집하지 않습니다. 연결 해제 또는 계정 삭제 시 삭제합니다.
애플 refresh token
Apple 로 로그인한 경우, 계정 삭제 시 애플 쪽 연결까지 실제로 철회하기 위해 애플이 준 refresh token 을 보관합니다. 삭제 시 함께 폐기하며, 철회 요청이 실패하면 암호화된 상태로 최대 7일간 재시도용으로 남긴 뒤 폐기합니다.
시도 기록
제출한 단어, 정답 여부, 시도 횟수, 제출 시각, 연속 기록·누적 정답 수입니다. 순위와 통계를 만드는 데 씁니다. 계정 삭제 시 삭제합니다.
구독 식별자
광고 제거 구독을 쓰면 App Store·Google Play 가 주는 구매 식별자(거래 ID·구매 토큰)와 만료 시각을 저장합니다. 결제 수단이나 카드 정보는 스토어가 처리하며 서버로 오지 않습니다. 계정 삭제 시 삭제합니다(구독 해지는 아래 이용약관 참고).
광고 ID
앱에서만 해당합니다. 앱에 넣은 Google AdMob SDK 가 기기의 광고 ID(iOS IDFA, Android 광고 ID)를 광고 요청에 씁니다. 이 값은 서버에 저장하지 않습니다 — SDK 가 AdMob 으로 직접 보냅니다. 기기 설정에서 광고 ID 를 초기화·삭제할 수 있고, 앱의 "광고 개인정보 설정" 에서 동의를 다시 선택할 수 있습니다(해당 지역).
접속·오류 기록
서비스 장애를 찾기 위해 요청 경로·시각·오류 스택이 서버 로그와 Sentry 에 남습니다. 이메일·토큰 같은 식별 정보는 마스킹해서 기록합니다. Sentry 보관 정책에 따라 일정 기간 후 자동 삭제됩니다.

서버 데이터베이스는 매일 1회 백업하고 백업본을 14일 보관합니다. 그래서 계정을 삭제하면 서비스에서는 즉시 사라지지만, 그 이전에 만들어진 백업본에는 최대 14일간 남아 있다가 순차적으로 폐기됩니다.

2. 이용 목적

  • 퍼즐 진행·연속 기록·순위·통계 제공
  • 여러 기기에서 같은 기록을 잇기 위한 계정 연결
  • 광고 제거 구독 상태 확인
  • 앱 광고 노출(구독자 제외)
  • 장애 대응과 서비스 개선

수집한 정보를 위 목적 밖으로 쓰지 않고, 광고·마케팅 목적으로 제3자에게 판매하지 않습니다.

3. 제3자 제공·처리 위탁

아래 업체가 각자의 기능 범위에서만 정보를 처리합니다.

Google (로그인, Firebase Analytics, Google Play)
구글 계정 연결 시 식별자·이메일, 앱 사용 이벤트(퍼즐 완료·공유·구독 화면 조회 등 집계용 이벤트), Google Play 구독 검증.
Apple (로그인, App Store)
Apple 계정 연결 시 식별자·이메일, App Store 구독 검증.
Google AdMob
앱 광고 노출·측정. 기기 광고 ID 와 광고 요청 정보.
Sentry
오류 추적. 오류 발생 시의 요청 정보와 스택.

각 업체의 처리 방침은 해당 업체가 공개한 정책을 따릅니다. 서비스에서 더 이상 필요하지 않게 되면 해당 업체에도 삭제를 요청합니다.

4. 국외 이전

위 업체(Google, Apple, AdMob, Firebase Analytics, Sentry)의 서버는 대한민국 밖 (주로 미국)에 있어, 해당 기능을 쓰는 동안 정보가 국외로 이전됩니다. 이전되는 항목·목적· 업체는 3절과 같고, 이전 기간은 각 기능을 쓰는 동안입니다.

거부 방법은 기능마다 다릅니다. 구글·애플 계정을 연결하지 않으면 로그인 제공자로 이전되는 식별자·이메일이 없고, 광고 제거 구독을 쓰지 않으면 스토어로 이전되는 구매 식별자가 없습니다. 그러나 계정을 연결하지 않아도 앱의 광고·앱 사용 이벤트·오류 기록은 그대로 전송됩니다 — 게스트로 쓰는 것은 국외 이전을 거부하는 방법이 아닙니다.

  • 광고(AdMob): 맞춤 광고 동의는 iOS 의 추적 허용 요청과 앱의 "광고 개인정보 설정"(표시되는 지역)에서 거부하거나 다시 고를 수 있습니다. 거부하면 맞춤 광고가 꺼지지만 광고 요청 자체는 여전히 AdMob 으로 갑니다. 광고 전송을 아예 없애려면 광고 제거 구독을 쓰거나 앱을 지워야 합니다.
  • 앱 사용 이벤트(Firebase Analytics): 앱에서만 발생하고, 지금은 개별 거부 수단을 제공하지 않습니다. 거부하려면 앱을 쓰지 않으셔야 합니다.
  • 오류 기록(Sentry): 웹·앱 모두에서 발생하고, 장애 대응에 필요해 개별 거부 수단을 제공하지 않습니다.

이 이전을 받아들일 수 없으면 서비스 이용을 멈추고 6절의 방법으로 계정과 기록을 삭제해 주세요.

6. 삭제와 이용자 권리

언제든 계정과 모든 기록을 지울 수 있습니다. 되돌릴 수 없습니다.

  • 웹: chosung.dosaem.com/account/delete
  • 앱: 내 기록 화면 맨 아래 "계정 삭제"

삭제하면 게스트 토큰, 시도 기록, 연결된 계정, 구독 식별자, 순위 등록분이 함께 사라집니다. 구독은 자동으로 해지되지 않습니다 — App Store 또는 Google Play 에서 따로 해지해야 결제가 멈춥니다. 열람·정정·처리 정지를 원하면 연락처로 요청하세요.

7. 보호 조치
