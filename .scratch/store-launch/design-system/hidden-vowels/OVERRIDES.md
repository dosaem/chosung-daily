# Hidden Vowels / 오늘의 초성 — 디자인 시스템 오버라이드

`MASTER.md` 는 UI UX Pro Max 가 생성한 베이스(Minimal & Swiss, Inter, 다크 기본)다.
이 파일이 MASTER 보다 우선한다. 인터뷰(2026-10-13)에서 "B 베이스 + 액센트만 따뜻하게" 로 확정.
웹(`web/`)과 Flutter 앱이 같은 토큰을 쓴다. MASTER 의 "Pattern"(랜딩페이지) 섹션은 이 앱과 무관하므로 무시.

## 1. 방향 한 줄

"매일 30초 집중". **Editorial Light** (NYT Games 결): 오프화이트 바탕, 검정 타이포가 주인공, 면 채움은 제출 버튼(검정) 하나뿐. 오렌지는 **가는 디테일**(불꽃, 스트릭 숫자, 활성 탭 밑줄, 포커스 링, 선택 칩 테두리)에만 쓰고 절대 면으로 칠하지 않는다. 다크 모드는 Soft Dark(채도 낮춘 네이비)로 짝을 맞춘다. 게임 피드백 색은 브랜드 색과 분리한다.
Stitch 목업 선택 기록: V0 Dark+Orange(촌스러움, 폐기) → V1 Editorial Light(채택, impeccable detect 0건) / V2 Soft Dark(다크 팔레트로만 차용, 면 위 밝은 글자는 대비 위반이라 금지).

Secondary(초록) 는 쓰지 않는다. 초록은 피드백 전용.

## 3. 타이포

- **본문/UI**: `Pretendard Variable` (ko, en 모두 커버) → 없으면 `Inter` → system-ui. 웹은 Pretendard CDN, 앱은 번들(OFL).
- **퍼즐 타일 글자**: 같은 Pretendard, weight 700, 크기 28–32pt. 영어 자음 뼈대 `_PPL_` 의 빈칸은 글자 대신 **빈 타일**로 표현(언더스코어 문자 쓰지 않음).
- 스케일: 12 / 14 / 16(기본) / 20 / 24 / 32. 본문 line-height 1.5.
- 한글 자간 -0.01em, 영문 0.

## 4. 간격·형태

- 간격 스케일 4/8/12/16/24/32/48. 카드 패딩 16(모바일) 24(태블릿+).
- 모서리: 타일 8, 버튼 10, 카드 16, 바텀시트 20.
- 그림자 없음. 라이트 모드에서 카드도 없음 — 섹션 구분은 헤어라인 1px 과 여백으로만. 바텀시트만 `card` 면을 쓴다.
- 터치 타깃 최소 44×44. 타일 간격 6, 타일 크기 48(5글자 이하) / 40(6~8글자) / 가로 스크롤 없이 줄바꿈(9글자+).

## 5. 광고 영역 규칙 (앱 전용)

- 배너는 화면 **하단 safe area 위**에 고정, 높이 공간을 **항상 예약**(로드 전에도 빈 영역 유지 → 레이아웃 점프 금지). 어댑티브 배너 사용.
- 배너와 콘텐츠 사이 `border` 1px + 8px 여백. 배너 배경은 `muted`.
- 전면 광고는 결과 시트가 완전히 뜬 **뒤** 1회. 보상형은 "힌트 미리 보기" 버튼에 광고 아이콘(재생 모양)과 "광고 보고 힌트" 레이블 병기.
- 구독자는 배너 영역 자체가 사라지고 콘텐츠가 그 자리를 채운다.

## 6. 컴포넌트 목록 (웹·앱 공통 이름)

`PuzzleBoard`(타일 행 × 시도), `GuessInput`(IME 안전, 길이 제한, 제출 버튼), `HintCard`(잠김/열림/미리보기 버튼), `ResultSheet`(정답, 분포 막대, 공유, 다음 퍼즐 카운트다운), `StreakBadge`, `LeaderboardRow`, `StatBar`(시도별 비율), `AccountCard`(연결/전환/삭제), `Paywall`, `LanguagePicker`, `ReminderPicker`, `OfflineBanner`, `MaintenanceScreen`, `AdBannerSlot`.

## 7. 상태 규칙

- 로딩: 스켈레톤(타일 자리·텍스트 줄). 스피너 금지.
- 퍼즐 없음(자정 전환 직후): "곧 새 퍼즐" + 카운트다운, 재시도 버튼.
- 네트워크 오류: 인라인 카드 + 재시도. 토스트로 숨기지 않는다.
- 오프라인: 상단 `OfflineBanner`, 입력 비활성.
- 빈 리더보드: "아직 아무도 못 풀었어요. 첫 번째가 되어보세요".
- 전환 모션: 200ms ease-out, 타일 뒤집기 350ms(행 단위 stagger 60ms). `prefers-reduced-motion` 이면 즉시 표시.

## 8. 아이콘·이미지

- 아이콘: Lucide (웹 SVG / Flutter `lucide_icons`). 이모지는 공유 텍스트와 스트릭 불꽃(🔥 → Lucide `flame` 으로 교체)에만 예외 없이 아이콘 사용.
- 앱 아이콘(2026-10-14 사용자 확정): **글자 없는 타일 3칸**이 가로로 나란히 — 양끝 두 칸은 `brand` 라이트 `#EA580C`, 가운데 "가려진" 한 칸은 `tile-wrong` 라이트 `#D6D3D1`, 배경은 `background` 라이트 `#FAFAF9`. 영문 스토어도 같은 아이콘(스토어는 앱당 아이콘 하나 — "ㅊ" 은 영어 사용자에게 뜻이 없어 언어 중립 모양). 참고 좌표(120 뷰박스): 배경 120×120, 타일 30×34 `rx=7` 을 x=12/46/80, y=43. **30px 확인 결과(티켓 35, 2026-10-15): 가운데 칸을 `#A8A29E` 로 한 단계 어둡게 했다.** `#D6D3D1` 은 배경 `#FAFAF9` 와 대비 **1.43:1** 이라 30px 로 줄이면 칸이 배경에 녹아 타일이 2칸으로 보인다. `#A8A29E` 는 **2.41:1**, 양끝 brand `#EA580C` 는 **3.41:1** 이다. 한 단계 더 어두운 `#78716C`(4.59:1)는 brand 보다 무거워져 "가려진 칸" 이 주인공이 되므로 쓰지 않았다. 래스터는 `design/icon-30px.png`, 원본은 `mobile/assets/icon/app_icon.svg`, 측정은 `mobile/test/store/app_icon_test.dart` 가 실제 픽셀로 다시 한다(README "35."). **이 변경은 아이콘 한 장뿐이고 §2 의 `tile-wrong` 토큰은 `#D6D3D1` 그대로다** — 보드 타일은 글자가 대비를 만든다. 스플래시는 같은 라이트 배경 + 같은 마크(라이트/다크 동일).
- 스토어 스크린샷: **라이트 모드 기준** 5장(홈/결과/리더보드/내 기록/언어 선택), ko·en 각각 — 앱 기본 톤(Editorial Light)과 일치. 다크모드는 앱에서 그대로 지원(§9).
