# 화면 명세 (DESIGN_DIR 의 일부)

토큰·컴포넌트·상태 규칙은 `../design-system/hidden-vowels/OVERRIDES.md`. 여기는 화면별 "무엇이 어디에" 만 적는다. **색·버튼·타일 표현은 OVERRIDES 토큰 이름으로 읽고, 이 문서와 충돌하면 OVERRIDES 가 우선한다** (주 버튼 = `primary-button`(검정/흰), 빈 타일 = `tile-empty`(면 채움, 테두리 없음), brand 는 아이콘·밑줄·테두리만).
목업 이미지는 `stitch/` (Stitch 생성) 또는 `mockups/` (HTML). 둘이 다르면 이 문서가 기준.

## 앱 탭 구조
하단 탭 3개: **오늘** · **순위** · **내 기록**. 탭 바 아래에 배너 광고 슬롯(구독자는 슬롯 자체 제거).
**폭 ≥600dp(iPad·Android 태블릿)** 는 하단 탭 바 대신 왼쪽 NavigationRail(같은 3항목) — 아래 "태블릿 레이아웃" 절. 판정은 기기 종류가 아니라 현재 폭(회전·Split View 대응).

## S1. 오늘 (게임 홈)
- 상단: 앱 이름(좌) / StreakBadge(우, flame 아이콘만 brand 색 + "N일" 은 foreground)
- 날짜 줄: "10월 13일 · 일반 단어" + 우측 작은 칩 "KST 00:00 새 퍼즐" (카운트다운은 결과 시트에서)
- PuzzleBoard: 문제 행(가림 타일 — `r` 은 글자, `h` 는 빈 타일, `s` 는 간격; 48px, bold) + 캡션 "N글자". 그 아래 시도 행 5줄(제출한 행은 서버 `attempts` 이력으로 correct/wrong 타일, 남은 행은 `tile-empty`)
- HintCard: 잠김(자물쇠 + "힌트는 3번째 오답 후 열려요" + 보상형 버튼 "광고 보고 힌트 미리 보기") / 열림(힌트 문장)
- GuessInput: 입력 + 글자수 카운터 "0/N" + `primary-button` "제출". 아래 "남은 기회 3/5". 제출이 409 `PUZZLE_CHANGED` 면 "새 퍼즐이 있어요" 인라인 + 새로고침
- 상태: 로딩=스켈레톤, 퍼즐 없음=카운트다운 카드, 오프라인=상단 OfflineBanner + 입력 비활성, 완료=입력 영역 대신 "결과 보기" 버튼

## S2. 결과 시트 (S1 위에 바텀시트)
- 제목: "정답은 지하철역!" / 실패 "아쉬워요, 정답은 지하철역"
- 내 결과: 🟩⬜ 그리드 요약(타일로 렌더, 공유 텍스트만 이모지)
- StatBar: 시도 1~5 별 정답자 비율 가로 막대, 내 시도 행 brand 색
- 다음 퍼즐 카운트다운 "다음 퍼즐까지 07:12:33"
- 버튼: "결과 공유"(`primary-button`, 네이티브 공유 시트), "순위 보기"(outline)
- 첫 완료 시 하단에 계정 연결 유도 1줄 "기록을 지키려면 계정을 연결하세요 →" (닫기 가능, 1회)
- 시트가 완전히 뜬 뒤 전면 광고 1회(구독자 제외)

## S3. 순위 (리더보드)
- 상단: 날짜 + 퍼즐 언어 칩(ko/en 전환은 설정에서, 여기선 표시만)
- 내 순위 카드 고정(상단): "#12 · 2회 · 00:03:41" — 리더보드 응답의 `me` 필드(21위 밖이어도 옴). 못 풀었으면 "아직 안 풀었어요"
- LeaderboardRow 목록 20개: 순위, "게스트 #a3f1"(게스트 번호 기반, 이메일 표시 없음), 시도 수, 걸린 시간. 내 행은 `is_me` 로 강조. 1~3위는 순위 숫자를 굵게(brand 색 글자 금지)
- 빈 상태: "아직 아무도 못 풀었어요. 첫 번째가 되어보세요"

## S4. 내 기록
- 상단 StreakBadge 크게: 현재 N일 / 최고 N일 / 누적 N문제 (3칸 카드)
- 최근 7일 미니 그리드(날짜별 성공/실패/미플레이 점)
- AccountCard: 미연결 → "구글로 연결" "Apple 로 연결" 두 버튼(Android 는 구글만) + 설명 "어느 기기에서든 같은 기록". 연결됨 → provider 아이콘 + 마스킹 이메일 + "전환됨" 안내
- 구독 카드: 미구독 → "광고 없이 플레이 · 월 {스토어 현지화 가격}" → Paywall. 구독 중 → "광고 제거 · 10/31 갱신"(유예 중이면 "결제 확인 중 · 유예 10/20 까지") + "관리"(스토어로)
- 백업 코드: "다른 기기 기록 불러오기" → 코드 입력 시트(웹 백업 코드) → 전환. 애플 계정 게스트가 Android 로 옮기는 경로
- 설정 리스트: 퍼즐 언어, 일일 알림(시각; 권한 거부면 "알림 꺼짐 — 시스템 설정에서 켜기"), 리마인더 on/off, **광고 개인정보 설정**(UMP privacy options 가 required 인 지역에서만 표시), 개인정보처리방침, 이용약관, 오픈소스 라이선스, 버전
- 맨 아래 destructive 텍스트 버튼 "계정 삭제" → 확인 다이얼로그: "기록·계정이 전부 삭제되고 되돌릴 수 없어요. 구독 중이면 App Store/Google Play 에서 따로 해지해야 해요." [취소] [삭제]

## S5. 구독 (Paywall, 전체 화면 시트)
- 제목 "광고 없이, 매일 30초"
- 혜택 3줄 체크: 배너·전면 광고 제거 / 광고 없이 힌트 미리 보기 / 어느 기기에서든 유지
- 가격 카드 1개: "월 {스토어 현지화 가격}" (한국 ₩1,500; 자동 갱신 안내 소문자). 구매 진행 중(pending)이면 버튼 비활성 + "결제 확인 중"
- `primary-button` "구독 시작", 아래 텍스트 버튼 "구매 복원"
- 하단 소문자 링크: 이용약관 · 개인정보처리방침 (애플 필수)

## S6. 온보딩 (첫 실행, 3장 페이지뷰)
1. "하루 한 문제" — 큰 타일 ㅈㅎㅊㅇ, 설명 "초성만 보고 단어를 맞춰요" (en: `_PPL_` 타일, "자음만 보고 단어를 맞춰요")
2. "5번의 기회" — 피드백 타일 설명(초록=자리까지 맞음, 회색=아님)
3. "매일 이어가기" — streak 불꽃 + 알림 권한 사전 안내 "매일 아침 알려드릴까요?" → [알림 켜기] [나중에] (로컬 알림, 기본 09:00)
- 언어 선택은 1장 상단 칩(ko/en), 기본값 기기 언어
- 마지막에 iOS ATT 안내 1장 추가(iOS 만): "맞춤 광고 허용" 설명 후 시스템 프롬프트 → 그 다음 UMP 동의 폼(필요 지역). 광고는 UMP `canRequestAds` 뒤에만 로드

## S7. 점검 / 강제 업데이트 (전체 화면)
- 아이콘 + "잠시 점검 중이에요" + 예상 시각 / 또는 "새 버전이 필요해요" + 스토어 버튼

## 태블릿 레이아웃 (폭 ≥600dp, 2026-10-14 추가)

원칙: **폰 레이아웃 + rail + 폭에 따른 재배치**. 태블릿 전용 화면·새 컴포넌트는 없고, 같은 위젯이 열만 바꿔 앉는다. 타일·글자 크기는 폰과 같다(확대 금지). 카드 패딩은 OVERRIDES §4 의 태블릿 값(24). 목업 없음 — 아래 와이어 + 토큰으로 구현하고 `audit.native` 에 태블릿 폭(744·1024·1366)을 포함한다.

| 구간 | 폭 | 내비 | 콘텐츠 |
|---|---|---|---|
| compact | <600 | 하단 탭 바 | 폰 그대로 |
| medium | 600~839 (iPad 세로 Split View, 작은 태블릿 세로) | rail | 1열, `ReadingWidth` 최대 600 가운데 |
| expanded | ≥840 (iPad 세로 전체·가로, 태블릿 가로) | rail | 화면별 2열(T1·T4) 또는 넓은 표(T3) |

폭이 바뀌면(회전, Split View 크기 조절) 현재 탭·입력 중 텍스트·스크롤 위치는 유지되고 레이아웃만 바뀐다. iPad Split View 의 가장 좁은 폭(약 320)은 compact.

### T0. 셸 (모든 탭 공통, expanded 예: iPad 가로 1194×834)
```
┌──────┬──────────────────────────────────────────────────────┐
│ rail │  ReadingWidth / 2열 콘텐츠 (rail 제외 폭)             │
│ ◉오늘│                                                      │
│ ○순위│                                                      │
│ ○기록│                                                      │
│      │                                                      │
│      ├──────────────────────────────────────────────────────┤
│      │  배너 슬롯 — 콘텐츠 열 하단, rail 제외 폭의 어댑티브 높이│
└──────┴──────────────────────────────────────────────────────┘
```
- rail: 아이콘 + 라벨, 선택 표시는 OVERRIDES 토큰(brand 는 아이콘·밑줄만). 하단 탭과 같은 go_router 경로.
- 배너 슬롯은 rail 아래가 아니라 **콘텐츠 열 하단**, safe area 위. 폭이 바뀌면 새 폭으로 다시 로드하되 예약 높이 규칙(OVERRIDES §5)은 그대로. 구독자는 슬롯 제거.
- 온보딩(S6)·점검(S7)은 rail 없이 `ReadingWidth` 600 가운데(T0 의 콘텐츠 열만).
