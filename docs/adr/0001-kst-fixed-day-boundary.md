# "오늘"의 경계는 모든 지역에서 KST 자정으로 고정한다

> 정본. 계획 당시 원본은 `.scratch/store-launch/adr/` 에 그대로 있고, 갱신은 이 사본에 한다.

글로벌(ko/en) 출시를 하지만 오늘의 퍼즐·리더보드·통계·연속 기록의 "하루"는 플레이어 로컬 자정이 아니라 KST 자정 하나로 정한다. Wordle 식 로컬 자정은 서버가 클라이언트 날짜를 믿어야 해서 리더보드·통계 키가 날짜당 여러 개로 갈라지고 streak 판정이 시간대마다 달라진다. KST 고정이면 지금 코드(날짜 키 하나, Beat 자정 태스크)를 그대로 쓰고 UI 에 "매일 KST 00:00 에 바뀜"과 카운트다운만 보여주면 된다. 해외 유저 체감(낮에 바뀜)은 감수한다. 나중에 로컬 자정으로 바꾸려면 날짜 키 전부가 영향을 받으므로 되돌리기 어렵다.
